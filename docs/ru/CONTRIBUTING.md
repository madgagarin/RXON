# Руководство по разработке RXON

[EN](https://github.com/madgagarin/rxon/blob/main/CONTRIBUTING.md) | [ES](https://github.com/madgagarin/rxon/blob/main/docs/es/CONTRIBUTING.md) | **RU**

RXON является общим протокольным уровнем, поэтому изменения здесь напрямую влияют на зависимые сервисы и библиотеки.

## Настройка окружения

1. Склонируйте репозиторий и перейдите в корень проекта.
2. Установите пакет в режиме разработки:
   ```bash
   pip install -e .[dev]
   ```

## Тестирование и статический анализ

Запустите тесты, линтер и проверку типов:

```bash
pytest tests/
ruff check .
mypy src tests
```

## Требования к изменениям

- **Обратная совместимость**: изменения в `rxon.models` могут нарушить совместимость на уровне сетевого протокола. Согласовывайте такие изменения заранее.
- **Зависимости**: ядро библиотеки должно оставаться легковесным и без лишних внешних зависимостей.
- **Типизация**: строгая статическая типизация обязательна для всех моделей и публичных интерфейсов.
